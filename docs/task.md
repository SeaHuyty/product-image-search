## Your tasks: Building Product Image Search
Objective: Using the CLIP model and Fashion Product Image Small dataset, build a web page that allows users to:
  1. Search for products by describing the item (e.g. red dress, brown shirt)
  2. Search for products by passing another image.

The webpage should present the top 10 highest matching results as a list of items where each match has: (1) the product image (2) the product name, (3) the product description
